## 🌟 Trois projets pour commencer

### 🤖 [Assistant RAG pour Moodle](https://github.com/hyacinthe-waboe/projet-assistant-rag-moodle)

Mon projet de stage de L3, réalisé en binôme. L'assistant répond aux questions des étudiants à partir des PDF de leurs cours et indique ses sources dans Moodle.

J'ai participé au serveur Python et FastAPI, à la recherche documentaire avec FAISS et BM25, aux tests automatisés et à la documentation technique. Le dépôt contient le code et les explications pour reprendre le prototype.

### ☀️ [Direction Soleil](https://github.com/hyacinthe-waboe/projet-direction-soleil)

Un projet de M1 MIAGE réalisé à six pour une agence de voyages fictive : une base Oracle de 23 tables, des requêtes SQL et trois tableaux de bord Power BI.

J'ai contribué à la modélisation, à la préparation des données et aux corrections SQL. J'ai notamment travaillé sur la Synthèse direction pour suivre le chiffre d'affaires, le panier moyen et les voyageurs. Les scripts, le rapport, la présentation et la progression documentée du projet sont disponibles dans le dépôt.

### 🅿️ [DreamPark](https://github.com/hyacinthe-waboe/projet-dreampark)

Une simulation de parking développée en binôme en Python : entrée et sortie des véhicules, attribution des places, abonnements et suivi de l'activité.

Le projet comprend une interface CustomTkinter, des données enregistrées en SQLite et CSV, une modélisation UML et 119 tests unitaires. Les branches conservent les différentes étapes du développement.
